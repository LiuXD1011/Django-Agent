# MCP真实协议与Agent页面补验

Goal允许用受控本地MCP服务执行真实握手、工具发现和调用。本段使用已安装的官方SDK 1.32.1创建本地采购计算服务，工具`qa_purchase_total`只接受有界整数数量与单价，返回乘积及唯一回执；不访问文件、用户数据或外部网络。固定的测试凭据属于合成配置，不使用用户模型Key作为服务认证。服务器日志只记录方法、合成认证是否匹配、会话摘要和经过验证的计算结果，不记录HTTP头、任意请求正文或模型问题。

准备阶段由独立SDK客户端完成initialize、tools/list、tools/call和会话终止，明确标为服务自检，不能替代页面。所有服务器与客户端代码位于临时文件，证据与归档位于`docs/refactor-evidence/20261012-mcp-real-agent/`；准备不修改产品或冻结构建输入。

浏览器阶段由当前唯一GUI负责人执行，先通过设置表单创建本段自己的MCP记录。编辑名称时Key留空，再通过对话工具面板实际发现工具，以服务器认证记录核已保存凭据保留；禁用/启用用本记录，不改原服务。此部分不需要模型调用。

只有真实发现服务正常后，由根代理另明确安排一次对话，选择空知识库范围、已配置的GLM和该工具，请求计算12套、每套79元并给出服务回执。检查实际tool轨迹、服务器tools/call结果948、最终回答、主任务及维护任务的用量和终态；最多8条新增模型用量，不对失败或unknown重放，不以模型自行算出948代替真正调用MCP。开始前再核当前配置与已有四模型/key摘要。

完成后通过页面删除本段记录，核无活动任务与原模型/服务保持，再正常关闭自有服务器并删除已消费临时脚本。正式安装IPC的同功能另行复核；本计划不宣称MCP页面/Agent/安装已通过，也不伪装为已连接其他外部服务。
