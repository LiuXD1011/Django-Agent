# 文档状态筛选与统计统一

文档重解析保留已发布正文时，数据库 `parse_status` 可以继续为 `completed`，当前工作流则为取消、失败或中断。页面已显示当前工作流标签，但列表筛选和侧栏计数仍直接读取旧 `parse_status`；因此会出现“已取消”文档在“已取消 0”筛选中找不到的问题。

选择在核心统一计算筛选状态：当前等待、处理、失败、取消优先；中断计入失败筛选；其他情况保留已有解析状态。列表筛选、全库状态统计与统计接口共用此计算。原始 `parse_status`、正文、摘要、来源代次和工作流记录保持原值，不改权限或模型调用。旧文档没有工作流字段时使用原状态。

先用真实 SQLite/认证空间构造已发布内容的当前工作流回归，确认筛选和计数 RED，再做最小修复并验证相关知识库、文档和 HTTP 测试。实际 Orca 筛选仍必须点击复测，单元通过不替代页面验收。Goal II.3/4 已授权该普通修复；不提交，不改真实账户和密钥。
