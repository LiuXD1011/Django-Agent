# 分块详情关闭入口

2026-10-11，R-SOURCE-DRAWER-CLOSE。Orca 实际引用抽屉没有关闭按钮。已安装 TDesign 1.20.2 的 `closeBtn` 默认为未设置，实际渲染仅在它为真时显示关闭入口；点击遮罩中心落在抽屉内容上，不能据此认定遮罩关闭有缺陷。

显式启用关闭入口，并用带中文名称的原生按钮提供键盘操作。关闭、Escape 和遮罩统一经过现有页面的可见状态控制：有未保存正文或启停修改时提示先保存并保持抽屉打开；允许关闭时保留已有来源和路由语义。直接允许关闭会让现有未保存修改围栏阻止重新打开，因此必须同时保护关闭操作。暂不增加丢弃编辑的产品流程。

实施顺序：真实 Drawer 组件回归先验证关闭按钮和未保存编辑保护失败；最小修改详情页；执行引用相关测试、前端完整单元及构建；最后在 Orca 点击关闭、重新打开和键盘关闭，核对未保存内容及数据库未写入。新 Windows 包必须重新绑定当前源码。
