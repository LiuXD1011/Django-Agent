# Wiki 图谱详情关闭入口

2026-10-11，Goal 第二节第3、4项已授权普通错误修复及记录设计后继续实施。

Orca正常点击真实生成的“晨星A项目”节点后，详情内容、表格及链接正确，但标题栏没有关闭按钮。实际截图为 [节点详情](../refactor-evidence/20261011-browser-model-page/235-root-wiki-node-drawer-screen.png)。已核查安装版本的 TDesign Drawer：`closeBtn`没有默认值，现有组件未显式启用。当前可以点击图谱背景或按Escape关闭，但详情缺少直观且可用键盘操作的关闭入口。

选择显式启用已安装 Drawer 的关闭插槽，使用原生按钮、中文无障碍名称和现有受控 `visible` 更新。继续保留背景点击、Escape、节点选择、邻域、编辑和来源跳转。不增加单独的遮罩或导航行为。与另加外部浮动按钮相比，此方案让入口固定在抽屉标题栏，并复用已有关闭机制。

先在现有真实组件测试夹具中增加可选的实际 TDesign Drawer，验证鼠标及键盘关闭后图谱和页面内容保持、没有HTTP写请求。确认缺失按钮导致测试失败后，再修改组件；运行Wiki相关检查和前端完整检查，随后在Orca真实节点详情中复测。安装版需由后续正式源码绑定打包重新验证，浏览器通过不计为安装版通过。
