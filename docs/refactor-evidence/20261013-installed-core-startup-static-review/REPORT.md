# 安装版 Core ready 前 exit 1：独立静态诊断

本轮结论为 **包装路径边界的高优先级候选，实际根因等待 Windows 定向 probe**。只读代码已确认：外部 bundled Node 收到的 bootstrap modulePath 位于 `resources/app.asar`，实际 bootstrap 完全 packed，普通文件系统没有这个脚本路径。此前通过的 native Node6／Electron RunAsNode6／普通 main3 与 prepare production Runtime6 均没有覆盖这一安装边界。本轮没有执行任何 native、harness、GUI、服务、clone、模型或数据操作，也没有修改生产源码、主验收文档或 Git。

原正常启动 **FAIL** 保留：[用户原图判定](../20261013-owned-runtime-installed-gui-preparation/user-provided-startup-failure-evidence.json)和[正常启动工具终态](../20261013-owned-runtime-installed-gui-preparation/normal-launch-tool-terminal.json)记录 Main PID19340／FILETIME134363478637834112、loading 页面及“本地核心已退出（代码1）”。Main 最终 exit0、Job active0 表示收尾，不表示 login、Core ready、业务 worker 或托盘退出通过。Core／worker 原 HANDLE 未采样不能推导进程不存在。原 v2 harness 静态／替身 review accept 与本次业务启动 FAIL 同时成立。
